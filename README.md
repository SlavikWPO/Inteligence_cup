# Intelligence Cup × «Газпром нефть»: ИИ-агент для ретрансляции обращений в поддержку

Решение кейса: ИИ-агент, который собирает обращения в поддержку, находит регулярно повторяющиеся просьбы и передаёт их продуктовым командам без дополнительной нагрузки на техподдержку.

## Прототип логики агента

Папка [prototype](prototype) показывает, что описанная логика работает: конвейер, маскирование персональных данных, порог по разным клиентам, защита от инструкций в тексте обращения и защита от дублей. Это иллюстрация реализуемости, а не часть конкурсного ответа. Вместо Qwen 3.8, Qwen-ASR и Qwen-VL используются прозрачные заглушки (`agent/llm.py`); подключение к внутренней модели вынесено в класс `QwenClient`. Данные синтетические, построены на примерах обращений «Вебнефти» из условия кейса.

Нужен только Python 3.10+, без установки пакетов и без интернета:

```bash
cd prototype
python3 -m agent                                   # ночной прогон на 24 обращениях
python3 -m unittest discover -s tests -t . -v      # 10 тестов
```

Что показывает прогон:

- пустое, служебное и повторное обращения отсеиваются до вызова модели;
- распознавание речи и изображений вызывается только когда без него не обойтись;
- телефоны, ФИО, ИНН и e-mail скрываются до модели и в сигналах;
- обращение с командой «игнорируй инструкции…» уходит на ручную проверку и не становится сигналом;
- пять обращений одного клиента не дают сигнала, а пять разных клиентов — дают;
- резкий рост темы за неделю даёт сигнал раньше порога;
- повторный запуск не создаёт дублей.
